# キー丸（カラオケ キー調整アプリ）実装手順書

自分の音域を登録すると、曲ごとに「何キー下げれば歌いやすいか」を表示するWebアプリ。
この文書は、機能一覧（たたき台）で決めた内容をもとに、実装の順番・設計・確認方法をまとめたもの。

- アプリ名: **キー丸**（キー変更を丸っと楽に）
- 公開先: https://kotarotakamatsu322.github.io/karaoke-key/ （master に push すると自動で公開）
- 進み具合（2026-10-17 時点）: 6章の ⓪〜⑧ はすべて完了。⑦ の複数プロフィールだけ見送った。
  ④ のあとカラオケで試した結果やアイデアから足した機能は、9章にまとめた

| 技術 | React + TypeScript + Vite、テストは Vitest |

## 2. 音の表し方

### 2.1 内部での値
音はすべて **MIDIノート番号（整数）** で扱う。1違うと半音1つ分の差になる。
キーの計算は、この数値の足し算・引き算だけで済む。

### 2.2 日本式の表記との対応
日本式の表記では、**A から次の G# までを1つのグループ**として扱う。

| グループ | 範囲 | MIDI番号 |
|---|---|---|
| lowlow | lowlowA〜lowlowG# | 21〜32（A0〜G#1） |
| low | lowA〜lowG# | 33〜44（A1〜G#2） |
| mid1 | mid1A〜mid1G# | 45〜56（A2〜G#3） |
| mid2 | mid2A〜mid2G# | 57〜68（A3〜G#4） |
| hi | hiA〜hiG# | 69〜80（A4〜G#5） |
| hihi | hihiA〜hihiG# | 81〜92（A5〜G#6） |

変換式: `MIDI = 21 + 12 × グループ番号 + Aからの半音数`
（グループ番号は lowlow=0, low=1, mid1=2, mid2=3, hi=4, hihi=5。
Aからの半音数は A=0, A#=1, B=2, C=3, C#=4, … , G#=11）

確認用の値: `hiA = A4 = 69`（440Hz）、`mid2C = C4 = 60`（ド）、`lowG = G2 = 43`

画面では「mid2G（G4）」のように、両方の表記を並べて表示する。

## 3. キー計算の仕様

### 3.1 入力
- 自分の音域: `low`, `high`（任意で `comfortableLow`, `comfortableHigh`）
  - 計算には `uLow = comfortableLow ?? low`、`uHigh = comfortableHigh ?? high` を使う
- 曲の音域: `songLow`, `songHigh`
- 合わせ方: `'high'`（最高音に合わせる）または `'center'`（音域の真ん中に合わせる）
  - 画面では両方を計算し、「高め」（high）と「低め」（center）として並べて出す（1章）

### 3.2 手順
1. **収まる範囲を求める**: 曲が自分の音域に収まるずらし幅は
   `minShift = uLow − songLow` 〜 `maxShift = uHigh − songHigh`
2. **原曲キーで歌えるか**: `minShift ≤ 0 ≤ maxShift` なら、ずらし幅は **0**（判定は「原曲キーで歌える」）
3. **理想のずらし幅 `s` を決める**
   - high のとき: `s = maxShift`
   - center のとき: `s = round(自分の音域の中央 − 曲の音域の中央)` を求め、`[minShift, maxShift]` の範囲に収める
4. **曲の音域の方が広い場合**（`minShift > maxShift`）: 全部は収まらないので、判定は「音域が足りない」。
   この場合も `s = maxShift`（高音側を優先）で表示し、出せない低音が何音あるかを添える
5. **カラオケ機での設定値に直す**
   - `−7 ≤ s ≤ 7`: キー `s`、オクターブはそのまま（判定は「キー調整で歌える」）
   - `s < −7`: 1オクターブ下で歌い、キーは `s + 12`（判定は「オクターブ下推奨」）
   - `s > 7`: 1オクターブ上で歌い、キーは `s − 12`（声が高い人向け）

6. **裏声が届くかを調べる**（キーには使わない）: 曲と自分の両方に裏声の最高音があれば、
   `曲の裏声の最高音 + s − 自分の裏声の最高音` が 0 より大きいとき、その半音数を「届かない」として返す

### 3.3 出力
```ts
type KeyResult = {
  shift: number;          // 実際に下げる・上げる半音数（例: -9）
  machineKey: number;     // カラオケ機で設定する値（例: +3）
  octave: -1 | 0 | 1;     // 原曲から何オクターブずらして歌うか
  status: 'original' | 'adjusted' | 'octaveDown' | 'octaveUp' | 'tooWide';
  shiftedLow: number;     // ずらした後の曲の最低音
  shiftedHigh: number;    // ずらした後の曲の最高音
  missingLow: number;     // 自分の音域より低くて出せない半音数（0なら問題なし）
  falsettoShortage: number; // 裏声が届かない半音数（どちらかの裏声が未登録なら 0）
};
```

## 4. データの形

```ts
type VoiceProfile = {
  low: number; high: number;                 // 限界の音域（地声、MIDI）
  comfortableLow?: number; comfortableHigh?: number;
  falsettoHigh?: number;                     // 裏声の最高音（裏声が届くかの注意に使う）
};

type Song = {
  id: string; title: string; artist: string;
  low: number; high: number;                 // 地声の音域（MIDI）
  falsettoHigh?: number;                     // 裏声の最高音（地声の最高音より低くてもよい）
  favorite?: boolean;                        // ★十八番
  female?: boolean;                          // 女性曲（キーの計算には使わず、目印と絞り込みに使う）
  memo?: string;
  createdAt: string; updatedAt: string;
};

// 保存データには残っているが、画面では使っていない（高め・低めを両方出すようにしたため）
type Settings = { alignMode: 'high' | 'center' };

// ⑤ で追加。オクターブ違い（例: オクターブ下のキー +3 と、そのままのキー +3）を区別するため、
// カラオケ機の値ではなく、原曲からずらした半音数（shift）で持つ
type SingRecord = {
  id: string; songId: string; shift: number;
  rating: 'tooHigh' | 'good' | 'tooLow'; date: string;
};
```

localStorage のキーは `karaoke-key:v1` にまとめ、`{ version, profile, songs, settings, records }` の形で保存する。
読み書きは try/catch で囲み、失敗した場合は空のデータで起動する。

- スマホの画面幅（360px程度）で見やすく表示できることを確認する
- **完了の条件**: スマホで一通り操作できる → **実際にカラオケで1回使ってみる**

### ⑤ 試聴機能と歌った記録（A・D） ✅ 完了
- 試聴: `NoteSelect` の横に ▶ ボタン。Web Audio API の OscillatorNode で約1秒鳴らす
  （あとで、声らしい「あー」の音に変えた。9章）
- 記録: 曲ごとに「歌ったキー＋高すぎ／ちょうどいい／低すぎ」を保存する
  （最初は「楽／ちょうどいい／きつい」の予定だったが、きついだと高すぎか低すぎかが分からないため変えた）
- 補正: 直近の記録が「高すぎ」なら -1、「低すぎ」なら +1、「ちょうどいい」ならそのままを、
  「高め」「低め」の下に3行目「記録から」として出す（最初は単純なルールにする）
- **完了の条件**: 記録が残り、次に開いたときに補正したキーが提案される

### ⑥ CSVの取り込み・書き出し、曲データの追加（F） ✅ 完了
- CSVの形式: 見出し `曲名,アーティスト,最低音,最高音,裏声の最高音,十八番,女性曲`（`title,artist,low,high` の見出しや、裏声・印の列なしも読める）。
  印の列は「○」か空。印の列がない CSV で上書きしても、今の印は残す。
  音名は日本式・国際表記のどちらでも読み込め、書き出しは日本式。Excel で文字化けしないよう BOM を付けて書き出す
- 曲名とアーティストが同じ曲は、CSV の値で上書きする（曲の ID はそのままなので、歌った記録も残る）
- 取り込むときに、読めなかった行を行番号つきで一覧に表示し、ほかの行は取り込む
- 主な曲のデータは、自分で調べた値を CSV で用意する（音域まとめサイトから自動で取ってこない）
- **完了の条件**: 書き出した CSV をそのまま取り込み直すと、元と同じデータになる

### ⑦ その他（G）— 使いながら必要なものだけ ✅ 完了（複数プロフィールは見送り）
- 女性曲フラグ → 曲の印「★十八番」「女性曲」と絞り込み（十八番・女性曲・原曲キーで歌える）にした。
  女性曲の印はキーの計算には使わない（曲が高すぎれば、計算がもともと「オクターブ下推奨」にするため）
- 複数プロフィール（友達の分）→ **見送り**（ユーザーが判断）。作るなら、曲のリストを共通にするか、
  十八番を人ごとにするかを先に決める

  ページはネットを先に試してだめならキャッシュ、JS・CSS などはキャッシュを先に使う。`sw.js` を変えたら中の VERSION を上げる

### ⑧ マイクで音域を測る（E） ✅ 完了
- `getUserMedia` でマイクの音を取り、自己相関法などで声の高さを検出する
- 雑音対策: 音量がしきい値より小さい部分を無視する／一定時間（例: 0.5秒）続いた音だけを採用する
- 検出した最低音・最高音を、確認したうえで音域に登録する
  → 自己相関の仲間の YIN という方法で高さを調べる（`src/lib/pitch.ts`）。測った音は「出せる音域に入れる」「最高音を裏声の欄に入れる」で
  入力欄に入るだけで、保存はユーザーが「保存する」を押して行う。マイクは https（か localhost）のページでしか使えない
- 鍵盤アプリで試して見つかった問題（E2→E3、G6→G5、B6〜G7、F2 以下の精度）は、テストで再現してから直した
  - 基音が弱い音で 1オクターブ上（2倍）や 3倍の高さとまちがえないよう、周期の2倍・3倍で形が合うかを、サンプルのあいだを補って確かめる
  - 一度に調べる長さは 4096サンプル（低い音の周期が3回分以上入るように）、調べる範囲は 50〜4200Hz
  - 選べる音（lowlowA〜hihiG#）の外の音は「範囲外」と出して数えない
- **完了の条件**: 鍵盤アプリなどで鳴らした音を ±1半音以内で検出できる（`src/lib/pitch.test.ts` で、作った音を使って確かめている）

- ④ が終わったら、実際にカラオケで使って計算どおりに歌えるかを確かめ、⑤以降の優先順位を見直す

## 9. 手順書のあとで足した機能

④ のあとカラオケで試した結果や、ユーザーのアイデアから足したもの。どれも 1章・6章の該当するところにも反映してある。

| 機能 | きっかけ・理由 |
|---|---|
| キー幅 ±6 の機種の設定を添える | 実際に行った JOYSOUND がキー幅 ±6 だった。ずらし幅が ±7 のときだけ「±6: 1オクターブ下・キー +5」のように出す |
| 「高め」「低め」の2つのキーを並べる | カラオケで試すと、最高音に合わせる（高め）は少し高く、真ん中に合わせる（低め）は少し低かった。切り替えをやめて両方出す |
| 自分の音域の図 | 自分の音域を目で見て確かめたい。目盛り（low・mid1…）と、楽に出せる音域・裏声を重ねて描く |
| 一覧を最初からアーティスト順にする、アーティスト欄の候補 | 曲が増えても探しやすく、同じアーティストを入れ直さなくてよいように |
| 地声と裏声を分ける | 音域まとめサイトは地声と裏声を分けて書くことが多い。裏声の高い音でキーが下がりすぎないよう、キーは地声で決め、裏声は届くかの注意だけ出す |
| 名前「キー丸」 | 親しみやすい名前にしたい |
| 調整後の最高音を鳴らす ▶、声らしい試聴の音 | 歌う前に、そのキーでのサビの一番高い音を聞いて確かめたい。音は、のこぎり波をフォルマント（男性の「あ」）のフィルターに通し、ビブラートを付けた |
| 印（★十八番・女性曲）と絞り込み | 十八番だけ・原曲キーで歌える曲だけを見たい。女性曲フラグは計算に使わず、印にした |
| 「記録から」の3行目 | ⑤ の補正したキーを、高め・低めと並べて見たい |
| 検索欄の候補（アーティストと曲名） | 検索のときも、登録済みのアーティスト・曲名から選びたい |
